# Cyber Security Readiness Checker
An educational student portfolio website that asks small businesses about basic cyber-security controls and produces a simple readiness score.

## Features
- Eight security questions
- Readiness score and risk guidance
- Tailored improvement actions
- Print/save demo report
- Responsive design

## Topics covered
MFA, patching, backups, phishing awareness, endpoint protection, offboarding, passwords and incident response.

## Important limitation
This is not a real security audit and should not be used as professional advice. No answers are sent or stored.

## Technologies
HTML, CSS and JavaScript. Publish using GitHub Pages.
